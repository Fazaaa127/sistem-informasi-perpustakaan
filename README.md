# Sistem Informasi Perpustakaan

## Deskripsi Proyek
Sistem Informasi Perpustakaan merupakan aplikasi web sederhana untuk mengelola data buku. Aplikasi ini dibuat sebagai proyek tugas P02 Source Code Management & Version Control.

## Fitur
- Menambahkan data buku.
- Menampilkan daftar buku.
- Mencari buku berdasarkan judul, penulis, atau kode buku.
- Mencegah penggunaan kode buku yang duplikat.
- Menampilkan pesan ketika buku tidak ditemukan.

## Teknologi
- HTML
- CSS
- JavaScript
- Git dan GitHub

## Struktur Proyek
```text
IPSI PERPUSTAKAAN/
├── README.md
├── .gitignore
└── src/
    ├── index.html
    ├── style.css
    └── script.js
```

## Cara Menjalankan
1. Clone atau unduh repository ini.
2. Buka folder proyek.
3. Buka `src/index.html` di browser.
4. Tambahkan data buku melalui formulir.
5. Gunakan kolom pencarian untuk mencari buku.

## Catatan
Data buku hanya disimpan sementara di halaman browser. Aplikasi belum menggunakan database.
